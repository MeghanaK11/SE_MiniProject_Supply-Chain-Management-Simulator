# Deviation Log

Supply Chain Management Simulator, SE mini project. This log records every place where what we built or how we worked differs from the SRS v1.0 (SCM-SRS-001), the SAD v1.0 (SCM-SAD-001) or the Team Context Document. SRS v1.1 and SAD v1.1 point to this file in their revision history.

Last updated: 10-11-2026

| ID | SRS, SAD or plan said | What we built | Why | Impact | Section updated |
|----|----|----|----|----|----|
| DV-01 | Team Context Document: delivery in six rounds of features | Two sprints (Sprint 1 on 7 and 8 Nov, Sprint 2 from 9 to 11 Nov) run from a backlog with story points on a GitHub Project board | The course checklist requires a backlog, story points and sprints | Feature content is unchanged; only the schedule and tracking changed | None (process only) |
| DV-02 | Team Context Document: each author merges their own pull request after review | Every pull request is reviewed and then merged by the repository owner | Course checklist requirement | Authors open PRs; the repository owner squash merges them | None (process only) |
